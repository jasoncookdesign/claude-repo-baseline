# claude-repo-baseline

Baseline Claude Code config for personal repos.

- `python3 install_user.py [--dry-run]` merges `user/` into `~/.claude` (deny rules, the PreToolUse hooks, CLAUDE.md block), copies every `hooks/*.py` to `~/.claude/hooks/` and copies `skills/` (the `onboard-repo` skill). In `user/settings.json`, `{HOOKS_DIR}` stands for the installed hooks folder. Idempotent; writes `.bak` files. Restart Claude Code (or open `/hooks`) after installing so the hooks load.
- `python3 bootstrap.py OWNER/REPO --tier standard|scratch [--apply]` sets repo settings and opens a PR with `CLAUDE.md` and the branch-cleanup workflow. `CLAUDE.md` gets a marker-delimited block of the agentic-sdlc disciplines, fetched from `jasoncookdesign/agentic-sdlc` at its current `main` commit, so the disciplines load in every session, cloud included. An existing `CLAUDE.md` is kept, with the block added.
- `python3 bootstrap.py OWNER/REPO --disciplines [--apply]` refreshes only that block, opening a `chore/agentic-sdlc-disciplines-<sha7>` PR, or nothing when it's already current. It never creates a missing `CLAUDE.md`: onboard the repo with `--tier` first. With `--apply`, both modes refuse, exiting 1 without opening a PR (`--tier` has already applied the repo settings by then), when `CLAUDE.md` has disciplines content outside a BEGIN/END marker pair (an old unmarked block, a stray END marker, or the "Generated from jasoncookdesign/agentic-sdlc" line), since appending would duplicate it. Delete the old block and rerun. The rendering lives in `disciplines.py`. Commits in the clone use a pinned identity (Jason Cook, github@jasoncookdesign.com), not the global git config. Dry run by default.
- `hooks/guard_merge.py` refuses merges of PRs that touch `.claude/` or `.github/`.
- `hooks/higgsfield_gate.py` (matcher `mcp__claude_ai_Higgsfield__.*`, `onFailure: "block"`, which needs Claude Code v2.1.295 or later) keeps Claude from spending Higgsfield credits on its own:
  - `generate_image`, `generate_video`, `generate_audio` and their `_batch` variants are denied unless a single-use gate token exists for each request in the call (a single call with `count` N needs N). The `/reels:assets` skill in `jasoncookdesign/claude-skills` writes one on `reels.py record RUN.md GEN-ID submitted`, which re-runs `check-submission` and counts the attempt. Tokens live 15 minutes. The hook deletes them, oldest first, when it lets the call through, whether or not Higgsfield then submits a job; `reels.py record … generated|failed` deletes an ID's unused ones. A single call with `get_cost: true` is a free cost preflight and passes.
  - Read-only and free tools (`balance`, `transactions`, `jobs_wait`, the `show_*`, `list_*` and `get_*` reads, `models_explore`, `media_*` uploads, quotes, `ai_influencer_prepare`, `create_project`, `create_folder` and similar; the full list is `READ_ONLY` in the script) pass untouched.
  - Every other Higgsfield tool (`update_preferences`, `scene_builder_3d_*_python`, `execute_preset`, `motion_control`, `reframe`, `upscale_*`, `outpaint_image`, `remove_background`, `generate_3d`, `apps_invoke`, the studio, influencer, voice and website tools, and any tool Higgsfield adds later) returns `ask`: a permission prompt you answer, which auto mode can't approve on its own.
  - Malformed hook input or a crash denies the call.
  - Tokens live in `$REELS_GATE_DIR`, default `~/.local/state/reels-gate/`, which must be yours with mode 0700 or no token in it counts, as `<GEN-ID>.<random>.json` files holding `{"version": 1, "gen_id", "run", "attempt", "created"}`, with `created` in Unix seconds. Set `REELS_GATE_DIR` only to point tests at a scratch folder; the hook and `reels.py` must agree.
  - Limits: the token says some approved request passed the gate in the last 15 minutes, but it isn't bound to the prompt in the call. Anything that can write to the token folder can arm the hook, so it guards against a skipped step, not a determined bypass. Outside the Reel workflow, `generate_*` calls are denied. Use the Higgsfield app for those, or add a request to a run record. The hook only sees the `claude_ai_Higgsfield` connector, so Higgsfield connected under another MCP name isn't gated. Two calls racing for too few tokens can both be denied and lose a token (never an overspend). `install_user.py` merges whole hook entries, so changing an entry's matcher or options later adds a second entry; remove the old one from `~/.claude/settings.json` by hand.
- Tests: `python3 -m unittest discover -s tests`
